### ✅ Método 2: Acessar Localmente (Desenvolvimento)

Se você quer rodar na sua máquina localmente:

#### Pré-requisitos
- Node.js 18+ instalado
- Git instalado
- Terminal/CMD aberto

#### Passo a Passo

**1. Clone o repositório**:
```bash
git clone https://github.com/Gustavo641/meu-imovel-pe.git
cd meu-imovel-pe
```

**2. Instale as dependências**:
```bash
npm install
```

**3. Vá para a pasta web**:
```bash
cd packages/web
```

**4. Inicie o servidor de desenvolvimento**:
```bash
npm run dev
```

**5. Acesse localmente**:
```
http://localhost:5173
```

O navegador deve abrir automaticamente!

### Primeira Vez (Criar Conta)

1. **Na página de login**, clique em **"Criar nova conta"**
2. **Preencha o formulário**:
   - **Nome**: Seu nome completo

### Login (Nas Próximas Vezes)

1. **Insira seu email**
2. **Insira sua senha**

## 📊 Acessando as Features Principais

### Dashboard
- **Automaticamente carregado** ao fazer login
- Vê resumo de leads
- Atividades recentes
- Quick stats

### Gestão de Leads
**No menu lateral**, clique em **"Leads"**
- Ver todos os leads
- Criar novo lead
- Editar leads existentes
- Filtrar por status/origem/cidade

### Funil de Vendas
**No menu lateral**, clique em **"Funil"**
- Visualizar leads em Kanban
- Arrastar leads entre colunas (drag-drop)
- Ver detalhes no sidebar
- Clicar em email ou telefone para contato

### Calendário
**No menu lateral**, clique em **"Calendário"**
- Ver mês completo
- Próximas visitas agendadas
- Navegar entre meses

### Agenda
**No menu lateral**, clique em **"Agenda"**
- Ver demandas/tarefas
- Criar nova demanda
- Definir prioridade
- Marcar como concluída

## 🚨 Se Tiver Problemas de Acesso

### Problema: "Não consegue acessar"

**Solução 1**: Limpar cache
```
Navegador → Settings → Clear Cache
Depois, recarregue: Ctrl+Shift+Del (Chrome)
```

**Solução 2**: Usar modo incógnito
```
Chrome: Ctrl+Shift+N
Firefox: Ctrl+Shift+P
Safari: Cmd+Shift+N
```

**Solução 3**: Verificar internet
- Verifique se tem conexão
- Tente outro site
- Reinicie o router

---

### Problema: "Erro ao fazer login"

**Verificar**:
1. ✅ Email está correto?
2. ✅ Senha está correta? (case-sensitive)
3. ✅ Conta foi criada primeiro?
4. ✅ Conexão com internet está OK?

**Solução**:
- Clique em "Esqueceu a senha?"
- Siga as instruções de recuperação

---

### Problema: "Erro ao criar conta"

**Causa comum**: Email já está em uso
- Use um email diferente
- Tente outro email de teste

**Rate limiting**: Muitas tentativas muito rápido
- Aguarde 15-20 minutos
- Tente novamente
